# marketing/

Finished, self-contained marketing pieces for Humans of ERP. Each file is a single
HTML document with the brand fonts and logos embedded as data URIs — open it in a
browser, no build step and no network.

Everything here follows [`DESIGN.md`](../DESIGN.md) and is built from the real
assets in [`design-system/`](../design-system/). Unlike `content/*.json`, these are
hand-authored — they are not regenerated by `npm run pipeline`.

## `linkedin-call-for-stories.html`

A call for contributors: one ready-to-paste LinkedIn caption plus a six-slide
carousel at 1080 × 1350.

- **Caption** — copy button, live character count, and the first 210 characters
  tinted in place so you can see what shows before LinkedIn's "…see more".
  Two alternate openers sit under the disclosure below it.
- **Carousel** — print the page (⌘P → Save as PDF). The print stylesheet
  paginates one slide per page at true size; upload that PDF to LinkedIn as a
  document post.

Copy is drawn from the site's own wording (the Share Your Story section and the
main hero). The theme counts on slide 4 are the live category tags across the 62
published stories in `content/stories.json` — re-check them before reposting:

```bash
node -e "const s=require('./content/stories.json');const c={};for(const x of s){if(x.status!=='publish')continue;for(const t of x.terms)if(t.taxonomy==='category')c[t.name]=(c[t.name]||0)+1}console.log(Object.entries(c).sort((a,b)=>b[1]-a[1]).slice(0,7))"
```

Note: slide 6 uses `logos/MT-Group.svg` for the co-brand, not the horizontal
lockup `DESIGN.md` names for the site footer — that file is a white wordmark and
disappears on the cream slide. A light-ground horizontal MT variant would let this
slide match the footer treatment.
